# Music Downloader для Android

Нативное приложение на Kotlin. Качает с Яндекс.Музыки треки, альбомы, плейлисты и подкасты — в FLAC или MP3, с обложкой, тегами и текстом песни.

Работает на **Android 7.0 и новее**.

## Установка

Скачайте **`MusicDownloader-vX.Y.Z.apk`** из [Releases](https://github.com/vladimir120307-droid/yandex-music-downloader/releases/latest) и откройте файл на телефоне. Android спросит разрешение на установку из этого источника — его нужно дать (приложения не из Play Маркета ставятся только так).

## Как пользоваться

1. Нажмите **«Получить токен»** — откроется страница входа Яндекса
2. Войдите и разрешите доступ. Вас перебросит на адрес, содержащий `access_token`
3. Скопируйте адрес целиком, вставьте в поле токена и нажмите **«Сохранить»** — приложение само достанет нужную часть
4. Вставьте ссылку на трек, альбом, плейлист или подкаст
5. Выберите качество и нажмите **«Скачать»**

Можно проще: в приложении Яндекс.Музыки нажать «Поделиться» и выбрать Music Downloader — ссылка подставится сама.

Файлы сохраняются в папку **Музыка/MusicDownloader** и сразу видны в любом плеере.

## Качество

| Вариант | Что получится |
|---|---|
| **Авто** | FLAC, если есть подписка Плюс и у трека есть lossless-версия, иначе MP3 320 |
| **FLAC** | Lossless 16 бит / 44.1 кГц. Нужна подписка Яндекс.Плюс |
| **MP3 320** | Работает у всех, около 10 МБ на трек |

Яндекс отдаёт lossless внутри MP4-контейнера, поэтому приложение переупаковывает его в настоящий `.flac` прямо на телефоне — без перекодирования, аудио остаётся побайтово тем же. Отключить можно галочкой.

## Сборка из исходников

Нужен JDK 17 и Android SDK.

```bash
cd android
gradle assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/`.

APK подписывается ключом `release.keystore` из репозитория. Он лежит в открытом виде намеренно: приложение раздаётся через GitHub, а не через Play Маркет, и подпись нужна лишь для того, чтобы Android разрешил установку и корректно ставил обновления поверх старой версии. Для публикации в Play Маркете понадобится собственный закрытый ключ.

## Как устроено

```
app/src/main/java/ru/ymd/downloader/
  MainActivity.kt    — интерфейс на Jetpack Compose
  YandexMusic.kt     — клиент API: разбор ссылок, метаданные, ссылки на аудио
  Crypto.kt          — подпись запросов и расшифровка потока (AES-CTR)
  FlacRemux.kt       — переупаковка FLAC из MP4 в нативный .flac
  Id3.kt             — теги и обложка для MP3
  Downloader.kt      — скачивание и сохранение в папку Музыка
  Settings.kt        — настройки
```

Логика API повторяет проверенные реализации из расширения и десктопной версии этого же репозитория.
