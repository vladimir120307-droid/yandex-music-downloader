# 🎵 Yandex Music Downloader

Расширение для браузера Edge (и других Chromium-браузеров) для скачивания треков с Яндекс Музыки.

## Возможности

- **Скачивание текущего трека** — жёлтая кнопка ⬇ на странице
- **Кнопки на каждом треке** — скачивай прямо из списка
- **Скачивание альбомов и плейлистов** — кнопка "Скачать альбом/плейлист" на соответствующих страницах
- **Popup** — быстрый доступ к скачиванию текущего трека
- **Выбор папки** — можно включить диалог "Сохранить как"
- **Поддержка доменов** — `.ru`, `.kz`, `.by`, `.ua`, `.com`

## Как работает

Расширение перехватывает реальный аудио-поток из плеера Яндекс Музыки через `chrome.webRequest` API. Это тот же URL, который браузер использует для воспроизведения — полный трек, не превью.

**Принцип:**
1. Плеер загружает трек → расширение ловит URL аудио-файла
2. Нажимаешь кнопку скачивания → файл сохраняется как `Артист - Название.mp3`
3. Если перехваченного URL нет → фоллбэк через API Яндекс Музыки

## Установка

1. Скачай или клонируй этот репозиторий
2. Открой `edge://extensions` (или `chrome://extensions`)
3. Включи **Режим разработчика**
4. Нажми **"Загрузить распакованное расширение"**
5. Выбери папку с файлами расширения
6. Зайди на [music.yandex.ru](https://music.yandex.ru) или [music.yandex.kz](https://music.yandex.kz)
7. Включи трек и скачивай!

## Требования

- Браузер на базе Chromium (Edge, Chrome, Яндекс Браузер и др.)
- Авторизация в Яндекс Музыке (расширение использует cookies)

## Структура проекта

```
├── manifest.json      # Конфигурация расширения (Manifest V3)
├── background.js      # Service Worker — перехват аудио URL, скачивание
├── content.js         # Content Script — UI кнопки, API запросы
├── content.css        # Стили кнопок и уведомлений
├── popup.html         # Popup расширения
├── popup.js           # Логика popup
├── popup.css          # Стили popup
├── downloader.py      # Десктопная программа (Python + tkinter)
├── requirements.txt   # Зависимости для Python
└── icons/             # Иконки расширения
```

## Десктопная программа

Помимо расширения есть десктопная программа на Python — для скачивания по ссылке:

```bash
pip install requests
python downloader.py
```

Вставляешь ссылку на трек/альбом/плейлист, выбираешь папку, скачиваешь. Нужен OAuth-токен Яндекса.

## Скриншоты

### Кнопка на странице
Жёлтая круглая кнопка справа внизу — скачивает текущий играющий трек.

### Popup расширения
Показывает название и артиста текущего трека с кнопкой скачивания.

## Технологии

- **Manifest V3** — современный формат расширений Chrome/Edge
- **chrome.webRequest** — перехват аудио-потоков
- **chrome.downloads** — сохранение файлов
- **MutationObserver** — отслеживание SPA-навигации
- **Python + tkinter** — десктопная программа
